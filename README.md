# 观澜 · A 股与 ETF 监控

个人本地优先的分钟级监控应用。自选管理、多周期技术指标、复杂条件筛选和后台报警共用同一套计算引擎。

**Android 独立版：** `dist/android/guanlan-0.3.1.apk`，支持 Android 8.0+ ARM64。手机自行采集行情、计算指标、运行规则、保存数据和发送系统通知，电脑可以关机。首次打开无需地址或配对码；后台监控在顶部“运行”开启。网页和 App 共用源码，新增功能后重新构建、安装新版 APK。完整说明见 [安卓安装与更新](docs/android.md)。

**已接入免 Token 真实行情：东方财富 / 新浪自动备用 + 新浪交易日历。** 电脑新建数据库默认使用演示，手机独立版默认使用免 Token 真实源；可在“数据与设置”选择“真实行情 · 免 Token / 自动备用”，无需注册或填写密钥。

## 本地运行

推荐 Python 3.12（最低 3.11）。macOS / Linux：

```sh
python3.12 -m venv .venv312
.venv312/bin/python -m pip install -r requirements-dev.txt
./start.sh
```

打开 **http://127.0.0.1:8787**。API 文档：http://127.0.0.1:8787/docs 。

Windows 可创建 `.venv` 后执行 `.venv\Scripts\python -m pip install -r requirements-dev.txt`，再用 `.venv\Scripts\python -m backend` 启动。

端口可在 `.env` 设置 `MONITOR_PORT=8787`，也可用环境变量覆盖。启动脚本从项目目录加载 `.env`。按 Ctrl+C 停止。网页关闭后，只要服务和电脑仍在运行，监控就会继续；电脑休眠时不会监控。

## 可以使用的功能

- **自选监控**：添加、移除股票和 ETF；价格、涨跌幅、成交额、日线 RSI、近期走势。
- **K线图**：1/3/5/10/15/30/60/120 分钟、日、周、月；BOLL 主图叠加；副图指标切换、参数调整、悬停读数。在指标库选择“看图”可查看其他指标。
- **指标库**：当前锁定环境有 245 种可用计算函数，含标准技术指标、形态识别、统计函数与 A 股补充。完整清单由 `/api/indicators` 返回；MAVP 因需要外部动态周期序列暂未开放，并明确标注。
- **筛选工作台**：可视化条件生成器、可直接编辑的表达式、模板、跨周期运算、逐标的判定依据。
- **后台规则**：新增、编辑、暂停、删除规则；首次命中或假→真时记录事件；持久化去重，重启不会重复生成相同事件。
- **个性化报警**：在自选列表点击某只标的的“配置规则”，默认只选中该标的。每只股票/ETF 可配置多条规则，分别设置指标、周期、阈值及启停；也可明确选择多标的共用或全部自选通用。右侧按标的查看全部适用规则。
- **盘中筛选**：独立入口，按已保存、已启用且适用于该标的的报警规则筛选，任一规则命中即可入选。一个标的合并展示所有命中规则、表达式、版本、指标数值和 K 线时间。支持手动筛选、盘中每分钟自动刷新，以及查看全部标的/数据待确认/尚未配置状态。
- **报警中心**：保留规则版本对应的表达式、指标值、K线时间、数据源及发送状态；已读管理。
- **被动提醒**：站内记录默认启用；网页打开时可申请桌面通知；配置 SMTP 后可离开网页收邮件。邮件发送失败会重试。未启用邮件时产生的信号不会在以后配置邮件时补发。
- **Android 独立运行**：共享网页界面和 Python 业务引擎打包进 APK，手机本地计算与存储。支持本地系统报警通知和每次最长 5 小时 45 分的后台会话；系统省电可能延迟调度。两端分别保存数据，可导出 / 合并导入自选与规则。

## 行情接入

### 免 Token 真实行情

0.3.1 修复单一行情源断连导致的空图表，加入新浪备用源；错误按原因合并，手机自选页增加“当前标的 → 配置该标的规则”入口。新浪日线未提供成交额时留空，依赖成交额的指标 / 规则返回未知。1 / 3 分钟遇到集合竞价缺口保留为空，递推指标需重新预热。数据源切换时重新下载该周期历史，避免混接不同口径的序列。

在“数据与设置”选择 **真实行情 · 免 Token / 自动备用** 并保存。支持沪深股票和场内 ETF；北交所暂不在该源的验证范围内。当前工作空间已切换为真实行情、60 秒更新。

- 行情通过带超时的 HTTP 请求读取东方财富公开 K 线接口，失败时自动使用新浪分钟 / 日线接口；参考 [AKShare 股票接口](https://akshare.akfamily.xyz/data/stock/stock_quote.html) 和 [ETF 接口](https://akshare.akfamily.xyz/data/fund/fund_public.html)。交易日历来自新浪，使用经过完整对照验证的 Python 日历解码器解析，无需 JavaScript 引擎，不执行远程脚本。
- 分别读取 1/5/15/30/60 分钟及日线原始 OHLCV。3 分钟由 1 分钟、10 分钟由 5 分钟、120 分钟由 60 分钟聚合。成交量统一为股/份，成交额为元。
- 2026-11-07 实测初次返回：1 分钟约 1 个交易日；其他分钟周期约 31 个交易日，具体长度由上游决定。本地 SQLite 持续累积历史。较长参数、上市较短或数据缺失时可能无法完成指标预热，会返回未知。
- 各周期只在新的已完成 K 线出现后刷新，休市复用已确认数据。缺失交易分钟保留为空值；递推指标从缺口之后重新预热，日内 VWAP 出现缺口后当天保持未知。
- 两个接口均故障时保留历史用于查看，同时暂停信号判断；短时退避后自动重试。页面展示行情本身的时间，缓存不会被标为新行情，也不会混入演示数据。
- 当前公开交易日历已验证覆盖到 2026-12-31；超出覆盖范围时暂停判断，避免把未知节假日当成交易日。

公开接口无稳定性或延迟承诺。当前完成了休市时段联调：6 个自选（3 只 ETF、3 只股票）的行情时间为 **2026-11-06 15:00**，11 个周期均可计算默认 MACD。盘中连续更新、实际到达延迟仍需在交易时段观察。

可复核接口连通性和隔离数据验证（会请求公网，但不会改动当前监控数据库）：

```sh
.venv312/bin/python scripts/probe_public_market.py --adapter
```

## 计算约定

- 时区统一为 `Asia/Shanghai`；K线标签代表结束时间。
- **只使用已完成的 K 线**。例如 14:37 的 15 分钟周期引用 14:30 的 K 线；日线引用最近已完成的交易日。
- 分钟聚合分别以早、午交易时段起点对齐，不跨午休；日线聚合周/月线；真实行情用交易日历判断周/月是否结束。
- 当前全部按**不复权**口径。除权除息、ETF 分红或份额拆分可能影响跨日技术指标，复权因子接入在后续阶段完成。
- TA-Lib 采用其公开公式；MACD 柱值为 `DIF − DEA`（部分软件显示其两倍）。补充 KDJ 使用 `SMA(X,N,1)` 递推，初值 K=D=50；BOLL 使用总体标准差。
- 参数预热不足、无效除法、缺失行情返回未知值；未知条件不会产生报警。布尔运算采用三值逻辑，例如“未知 OR 真”为真。
- `REF`、滚动统计在输入序列的原生周期执行；跨周期只向前引用已完成数据，不回填未来值。跨周期复合表达式的滚动窗口以合并时间轴上的观察点计数，建议把滚动运算放在单一周期子条件内。
- 演示行情是按工作日构造的确定性合成数据，不包含真实节假日，也不模拟证券上市时间。

## 为不同标的设置报警与盘中筛选

1. 打开“自选监控”，在目标标的行点击“配置规则”。
2. 选模板或组合条件，填写专属规则名称；调整表达式里的周期和阈值，确认“适用标的”只勾选目标标的。需要完全不同条件时，分别新建规则。
3. 勾选“启用自动监控和盘中筛选”，保存。关闭该勾选可保存为暂停状态。通用规则仍会作用于全部自选；编辑通用/多选规则会影响其全部适用标的，界面会显示范围。
4. 进入“盘中筛选”，默认仅列符合条件的标的。展开可查看每条规则的判定依据；“全部标的与状态”也显示未命中、缺失数据和没有启用规则的标的。

报警和已保存规则筛选共用同一个判断流程。手动筛选只读计算结果，不发送邮件，也不改变报警去重状态；持续命中仍保留在筛选列表，后台提醒按首次命中或假→真去重。

真实源按 `Asia/Shanghai` 和交易日历运行，分钟监控覆盖 09:30–11:30、13:00–15:00（包含收盘集合竞价；11:30/15:00 这一分钟处理刚完成的 K 线）。未开盘、午休、非交易日及收盘后显示“休市参考”，暂停新增报警；可手动复核最近完成行情。集合竞价开盘前和盘后固定价格交易不在本监控时段内。时段依据：[上交所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)、[深交所交易时间说明](https://www.szse.cn/www/investor/knowledge/stock/deal/t20191204_572383.html)。交易日历未覆盖当前日期时不产生真实报警。演示源明确标注为演示，可随时体验。

页面每分钟刷新可单独暂停，后台规则仍按“数据与设置”中的间隔执行。筛选范围当前仍为自选池。

API：`GET /api/rules?symbol=510300.SH` 返回该标的适用规则（含通用及暂停规则）；`GET /api/rule-screen` 读取最新已启用规则筛选，`POST /api/rule-screen` 手动重新计算；`GET /api/status` 返回交易时段状态。规则写入仍使用 `/api/rules`，`symbols=[]` 表示全部自选，指定列表表示仅适用于这些标的。

## 规则示例

日线多头趋势：

```text
CLOSE(tf="1d") > MA(20, tf="1d") and RSI(14, tf="1d") > 50
```

分钟金叉与日线趋势同时满足：

```text
CROSSUP(MACD(tf="5m", line="dif"), MACD(tf="5m", line="dea"))
and CLOSE(tf="1d") > MA(20, tf="1d")
```

编辑器支持跨行表达式，也可以添加括号明确条件分组：

```text
(
  RSI(14, tf="15m") < 35
  and BIAS(6, tf="15m") < -2
)
```

其它函数：`REF`、`HHV`、`LLV`、`SUM`、`AVG`、`COUNT`、`EVERY`、`EXIST`、`ABS`、`MAX`、`MIN`、`CROSSUP`、`CROSSDOWN`。默认周期为日线。多输出指标用 `line="..."` 选择分量，输出名可在指标库查看。

表达式仅支持白名单 AST，不调用 `eval` / `exec`，不支持任意 Python、文件访问、导入或网络操作。

## 结构与下一步

```text
backend/
  market.py        行情适配、标准化、周期聚合
  public_market.py  免 Token 真实行情、交易日历、缓存与缺口处理
  indicators.py    指标目录与统一计算
  rules.py         安全表达式解释器
  service.py       后台监控、事件去重、邮件队列
  trading.py       交易日与盘中/午休/收盘状态
  storage.py       SQLite 持久化
  main.py          HTTP API、输入校验、静态资源
web/               网页与 App 共用的 ES modules、响应式 CSS、SVG 图表
android/           Android 原生 WebView 壳、连接设置及地址校验
backend/mobile.py  配对认证与局域网代理；复用原有单个后台监控进程
docs/android.md    安装、连接、升级与打包说明
tests/             核心计算与 API 测试
data/              运行数据（不提交）
```

当前采用 FastAPI + NumPy/pandas/TA-Lib + SQLite，网页无需 Node 构建。Android 通过原生 WebView 加载同一套页面和 API，网页业务更新后 App 刷新即生效。原生权限、推送等改动才需要重新打包 APK；后续开发遵守 [双端检查约定](CONTRIBUTING.md)。

本地逻辑上限为 200 个自选、100 条规则；这不是容量压测结果。指标按规则按需计算，尚未实现全市场分片、依赖图共享或逐笔增量引擎。该版本为个人单用户：电脑入口仅监听回环地址；可选手机入口增加配对码、限次尝试、HttpOnly 会话及 Host / Origin 检查。它不是多用户账号系统，不应直接作为公网多人服务部署。

后续顺序：真实行情交易时段验收 → 复权与全量证券资料 → 指标口径对照与规则历史回放 → 计算任务拆分与全市场筛选 → 多用户认证/隔离 → 安卓后台推送。
